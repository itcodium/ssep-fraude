## Guía paso a paso para completar P5 (Evaluación con RAGAS)

P5 es la última etapa del proyecto. El objetivo es medir formalmente la calidad de las explicaciones que genera tu pipeline RAG + LLM, usando el framework **RAGAS**. El gate es: **faithfulness > 0.8** en una línea base reproducible.

**Requisitos previos:** Ollama debe estar corriendo con `llama3.2:3b` (ya lo tienes de P3). RAGAS usará ese mismo modelo local como "juez" evaluador, sin necesidad de APIs externas de pago. No necesitas levantar ningún servicio Docker nuevo; Langfuse (P4) sigue corriendo en segundo plano si lo tienes activo, pero P5 no depende de él.

### P5.1 — Instalar RAGAS y dependencias

**Comando:**

bash

pip install ragas langchain-ollama langchain-community

**Qué hace:** `ragas` es el framework de evaluación. `langchain-ollama` permite conectar RAGAS con tu modelo local de Ollama. `langchain-community` se usa para cargar documentos si decides generar el test set de forma sintética.

**Validación:** ejecuta `python -c "import ragas; print(ragas.__version__)"` y confirma que imprime una versión (0.1.x o superior). Si falla, comparte el error antes de continuar.
