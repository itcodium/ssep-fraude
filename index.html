02
Rutas de lectura
Tres caminos según tu objetivo

No todo el mundo necesita leer los 8 documentos. Depende de si vas a evaluar, implementar o escalar.

Ruta 01 · Evaluar — "¿esto aplica a mi problema?"

Para quién: decisor técnico antes de comprometer recursos. Duración: 1-2 días. Sin instalar nada.

  • Doc 0 · Base → leer §1-3 (contexto, arquitectura, contratos)
  • Doc 1 · Patrón → leer §1-3 (contexto, problema, solución)
  • Decisión: ¿cumple las 10 condiciones? Si sí → Ruta 02. Si no → parar.

Ruta 02 · Implementar — "quiero el sistema mínimo funcionando"

Para quién: equipo que va a construir. Duración: 4 semanas (perfil senior).

  • Doc 0 · Base → leer entero
  • Doc 0.5 · Plan → leer entero
  • Doc 0.6 · Setup → abrir al instalar cada peldaño
  • Doc 3 · MetalKube → leer §2 al llegar a P1-P3
  • Decisión al llegar a P5: ¿merece la pena escalar? Si sí → Ruta 03. Si no → el sistema ya es útil.

Ruta 03 · Escalar — "voy a producción industrial"

Para quién: equipo con volumen real o clientes enterprise. Duración: 6-9 meses.

  • Doc 1 · Patrón → leer entero
  • Doc 2 · Implementación → consultar por capa
  • Doc 3 · MetalKube → leer §5-7 (MVP, roadmap, decisiones)
  • Doc 0.7 · Escalado → abrir al instalar cada herramienta
✓ Regla común a las tres rutas Un peldaño a la vez. Nunca saltar. El error más común es intentar el sistema completo (Doc 3) antes de validar la base (Doc 0).

04
Empezar hoy
El siguiente paso concreto según tu situación

Si aún no sabes si el patrón aplica

30 minutos. Lee Doc 0 §1 y responde por escrito si tu problema cumple las 10 condiciones. Si no cumple al menos 7, el patrón no aplica.

Si ya sabes que aplica pero no tienes dominio concreto

2 horas. Ejecuta la Fase A del Doc 0.5 §2: elige dominio, escribe los 3 contratos, confirma las 3 reglas.

Si tienes dominio y quieres código funcionando

4-6 horas. Abre Doc 0.6 §3 e implementa el IMR del Peldaño 0. Tres archivos Python, ~150 líneas.

Si ya tienes el IMR funcionando

2 días. Ejecuta la Fase C (validación) del Doc 0.5 §4. Después sube a Peldaño 1 con Doc 0.6 §4.

Si ya has llegado al Peldaño 5

1 día de decisión. Aplica las 4 reglas del Doc 0.5 §9. Si todas son "sí", abre Doc 2 y planifica Peldaño 6+.

No hace falta leer los 8 documentos. Hace falta saber cuál abrir hoy. El resto vendrá cuando llegues.
